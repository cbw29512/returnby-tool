# ReturnBy

ReturnBy is a free, privacy-first return deadline calculator and refund tracker.

## Production

- Live site: https://returnby-tool.netlify.app/
- Netlify project: `returnby-tool`
- Production branch: `main`
- Build command: none
- Publish directory: `.`

## Privacy model

ReturnBy has no account system and does not upload purchase details. Saved returns use browser `localStorage`. Calendar reminders are generated in the browser as `.ics` files.

## SEO

The repository includes `robots.txt`, `sitemap.xml`, canonical metadata, structured data, a privacy page, and a real 404 page.
